## 5. Priority Actions

1. **🔴 Tokens `status` + corrigir tints da Agenda** — desbloqueia o caso de uso real. Hoje o sistema mente quando você troca de paleta.
2. **🔴 Tokens `motion` + `prefers-reduced-motion`** — base pra todas as interações futuras.
3. **🟡 Surface tonal + elevation + zIndex explícitos** — necessário para hierarquia visual quando entrar prontuário/financeiro.
4. **🟡 Estados completos do `Button` + alinhar `TextField` error** — vira template para outros componentes.
5. **🟢 Dark mode + density + validação de contraste em CI** — pode ir depois das telas reskinadas.
